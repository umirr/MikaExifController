# 미카의 EXIF 지우개

사진의 EXIF 정보(촬영 시각, 카메라 모델, GPS 위치 등)를 제거하고, 원하는 형식과 파일명으로 저장하는 Windows 앱입니다.

## 실행 및 이미지 변환

1. [v1.0 실행 파일](https://github.com/umirr/MikaExifController/releases/download/v1.0/MikaExifController_v1.0.exe)을 다운로드해 실행합니다.
2. **이미지 변환** 탭에 JPG, JPEG, PNG, WebP 또는 TIFF 파일을 끌어다 놓습니다.
3. 저장 폴더와 출력 형식(원본 유지, JPG, PNG, WebP)을 선택합니다. 파일명을 바꾸려면 사용할 규칙도 선택합니다.
4. **EXIF 제거 실행**을 누릅니다. 처리 결과는 작업 로그에 표시됩니다.

**원본을 보관하려면 다른 저장 폴더를 선택하세요.** 저장 폴더를 지정하지 않으면 원본 폴더에 저장하며, 결과 파일명이 같으면 기존 파일을 덮어씁니다. ‘원본 유지’는 출력 형식을 유지하는 옵션입니다.

## 파일명 규칙

**규칙 편집** 탭에서 한 줄에 한 규칙씩, 왼쪽에 찾을 이름을 쓰고 오른쪽에 새 이름을 씁니다.

```text
A=1
B=2
여행 사진=제주
```

출력 형식이 ‘원본 유지’라면 위 규칙은 `A.png`를 `1.png`로, `B.jpg`를 `2.jpg`로 바꿉니다. 파일명이 정확히 일치하는 규칙을 먼저 적용합니다. 정확히 일치하지 않으면 파일명에 포함된 규칙 중 가장 긴 것을 사용합니다. 일치하는 규칙이 없으면 원래 이름을 유지합니다.

| 편집 기능 | 사용 방법 |
| --- | --- |
| 전체 순서 지정 | 여러 줄에 적힌 이름에 위에서부터 번호를 붙입니다. 예를 들어 두 줄의 A와 B는 각각 `A=1`, `B=2`가 됩니다. |
| 빈공간 자동 채우기 | 오른쪽에 번호가 있는 줄만 순서대로 다시 매깁니다. `A=1`, `C=3`은 `A=1`, `C=2`가 됩니다. |
| 전체 복사 | 빈 줄과 줄바꿈을 포함해 편집기 전체를 복사합니다. |
| 글자 크기 − / + | 편집기 글자를 줄이거나 키웁니다. |

규칙은 여러 묶음으로 저장할 수 있습니다. **새 규칙**, **제목 변경**, **삭제**로 목록을 관리하고, **이미지 변환** 탭에서 사용할 묶음을 선택하세요. **TXT 불러오기**는 텍스트 파일을 새 규칙 묶음으로 가져오며, **TXT 내보내기**는 현재 묶음을 파일로 저장합니다.

## 설정과 백업

규칙과 설정은 실행 파일 옆의 `config.json`에 자동 저장됩니다. 다른 PC로 옮길 때는 실행 파일과 이 파일을 함께 복사하세요.
